# Disease Symptom Prediction

A machine learning project that predicts a disease from the symptoms a person enters.

## Dataset
Source: [Disease Symptom Prediction](https://www.kaggle.com/itachi9604/disease-symptom-description-dataset) on Kaggle.

Files used:
- `dataset.csv`: diseases and their symptoms
- `symptom_Description.csv`: description of each disease
- `symptom_precaution.csv`: precautions for each disease
- `Symptom-severity.csv`: severity weight of each symptom

## Project Files
- `Disease_Symptom_Prediction_final.ipynb`: main notebook with the complete code
- `disease-symptom-description-dataset.zip`: dataset zip used by the notebook

## Tools Used
Python, Pandas, NumPy, Scikit-learn, Google Colab

## How to Run
1. Open the notebook in Google Colab .
2. Upload `disease-symptom-description-dataset.zip` to Colab's `/content/` folder.
3. Run all cells in order.
